# 未注册摸底报告（零账号可获取面）

时间：2026-10-25　｜　前提：**不注册、不登录、不写入**，只做只读探测与静态解包
范围：`api.next.bspapp.com`（uniCloud 空间）、`live.xc58.icu` / `one.xc58.icu`（PHP + socket）、`星辰语音` APK、`api.aiobs.cn`（其第三方依赖）

## 0. 三句话

1. **uniCloud 那条线已经断了**：前端里那对 `spaceId/clientSecret` 对应的空间**已被删除**，任何调用都返回 `InvalidSpace.Deleted`——之前判断的"明文凭据泄露"实际已失效。
2. **PHP 侧反而敞开**：`api/v1.member/tmymember?merchid=N` 无鉴权且可遍历，一次请求就吐出该租户的完整配置；遍历到 3 家，说明这套系统是**白牌 OEM**，一家公司给多个"品牌"供货。
3. **APK 里挖到了钥匙**：安装包里硬编码了一个第三方**抖音弹幕 WebSocket 签名服务**的 `ApiKey`，实测能用。也就是说**不需要账号、不需要桌面采集端**，就能直接连抖音弹幕流——这是"零账号复刻"最关键的一块。

## 2. uniCloud：协议还原成功，空间已废弃

### 2.1 还原出的签名协议（可直接复用）

```js
// 来自 bundle 的 gw():
sign = HMAC_SHA256(key = clientSecret,
        msg = Object.keys(body).sort().filter(k => body[k])
                 .map(k => `${k}=${body[k]}`).join('&'))
// 请求
POST https://api.next.bspapp.com/client
Content-Type: application/json
x-serverless-sign: <sign>
x-basement-token: <accessToken>        // 仅 invoke 类调用
body: { method, params, spaceId, timestamp [, token] }
```

方法词汇表（bundle 里全部出现过的）：`serverless.auth.user.anonymousAuthorize`、`serverless.function.runtime.invoke`、`serverless.file.resource.*`。

### 2.2 实测

```json
POST /client  method=serverless.auth.user.anonymousAuthorize
→ 404 {"success":false,"error":{"code":"InvalidSpace.Deleted","message":"The space is already deleted."}}
```

**诚实标注**：我用错误的 `clientSecret` 重放，返回的是同一条错误——说明服务端在**校验签名之前**就先判空间是否存在，所以"空间已删除"成立，但**这次没法反向证明签名算法正确**（算法来自代码阅读，未获服务端确认）。

### 2.3 结论

- `spaceId=mp-75d84e3e-…`、`clientSecret=7fA0…==`、`spaceName=dev-free` 仍在前端，但空间已删 → **无数据面暴露**
- 之前报告里"clientDB 可能裸奔"这一条，实际风险为 **0**；保留判断依据备查
- 副产品：以后遇到同类 uniCloud 站点，可直接用这套协议做匿名探测

## 5. 关键发现：硬编码的抖音弹幕签名服务

`app-service.js` 里：

```js
async function getWssUrl(e){
  return await uni.request({
    url: "https://api.aiobs.cn/Douyin/Douyin/SignWss",
    method: "POST",
    data: {
      ApiKey: "apikey-dy-<已遮罩>",   // ← 硬编码在 App 内，属第三方服务凭据
      BrowserName: "Mozilla",
      BrowserVersion: "Mozilla/5.0 (Windows NT 10.0; Win64; x64) … Chrome/126.0.0.0 …",
      RoomId: e,
      UserUniqueId: "7410618736569206322"
    }
  })
}
```

实测（`RoomId=1`，仅验证签名可用，未连接）：

```json
{"Code":0,"Data":{"WssUrl":"wss://webcast5-ws-web-lf.douyin.com/webcast/im/push/v2/?app_name=douyin_web&…&room_id=1&signature=fsRYL8aP685Hvz2X&…"}}
```

意义：

- 抖音网页弹幕走 `webcast/im/push` 的 **protobuf + gzip** 帧，握手必须带 `signature`；这个服务就是替客户端算这个签名
- 拿到了签名 URL，等于**绕开桌面端 DOM 抓取**，直接订阅弹幕流：不受平台改版影响、不需要登录平台账号、不需要开浏览器
- 同一套代码逻辑在 App 里跑，说明移动端就是这么取弹幕的；桌面端用 DOM 抓取只是历史包袱

**这是"零账号复刻"的技术核心**：弹幕源解决了，剩下的只是解码（protobuf）与自己的业务逻辑。

## 6. 未鉴权接口的信息泄露面

| 接口 | 行为 | 价值 |
|---|---|---|
| `GET api/v1.member/tmymember?merchid=N` | 200，返回租户全配置 | 已用（见 §3） |
| `POST api/v1.token/build` | 随机账号 → `{"code":401,"msg":"账号不存在"}` | **账号枚举 oracle**（账号不存在 vs 密码错误可区分）；未做批量枚举 |
| `GET api/v1.token/userList?mobile=` | 缺参 → `{"msg":"mobile不能为空"}` | 按手机号查用户；**未提交任何手机号** |
| `GET api/v1.open/getdanmu?live_id=` | `{"msg":"结婚对象不能为空"}` | 参数名泄露（hunli 复用接口） |
| `GET socket/httpapi/checkApp` | `{"msg":"版本号不能为空,平台不能为空"}` | 参数名泄露 |
| `GET api/v1.liveapi/getport` | `401` | 已鉴权，正常 |
| `POST socket/index/bullet` | 缺参 / 假 live_id → `参数为空`→`直播间标识错误` | live_id 存在性 oracle（未用于枚举） |

## 7. 仍然需要账号的（4 条，未变）

| 项 | 为什么 |
|---|---|
| 真实 `live_id` 形态 | `addStream` 要 token；但可由 `getBullet`/`getport` 的参数名推断结构 |
| 弹幕→语音的触发规则（关键词/延迟/打断） | 在登录后的 `pages/live/live` 与 `api/v1.live/opent` 逻辑里 |
| 计费细则（0.40/时 的扣减粒度、卡密面额） | `charge*` 需 token |
| socket 推送帧格式 | 开播后才会建会话 |

## 8. 零账号路线能推进到哪

| 层 | 现在能否做 | 依据 |
|---|---|---|
| 弹幕采集（抖音） | ✅ 可做 | `aiobs SignWss` + protobuf 解码 |
| 弹幕采集（快手/B站/视频号…） | ⚠️ 部分 | 桌面端 DOM 选择器已知，可照抄；WSS 侧各平台需自研 |
| 多租户配置面 | ✅ 可读 | `tmymember?merchid=N` |
| 语音生成 | ✅ 自建 | 他们走 `erchuang.xc58.icu` + `makeAudio`；自建换任意 TTS |
| 声音克隆 | ✅ 自建 | 接口名已给出流程：`person → goKelong → kelong → changePerson` |
| 直播位/计费 | ⭕ 自建 | 不需要他们的规则，自己定义 `live_id` 与时长扣减 |
| 与他们云端互通 | ❌ 必须账号 | 服务端只认 `live_id` + token |

## 10. 一句话收尾

**不用账号，已经拿到了「弹幕怎么来」和「系统怎么分层」；账号只能补「他们的业务规则怎么定」。** 复刻的真正缺口从来不是账号，而是语音质量与多平台稳定性——这两样谁的账号都给不了。
