# 接口台账

> **已确认项**（实测/读码得到）见 [03-逆向结论.md](03-逆向结论.md) §3 的 13 条接口与 §5 的弹幕协议；
> 本文件用于继续补齐「需登录后才能验证」的字段（真实 live_id 格式、语音触发规则、socket 推送帧）。
>
> 填写规则：一行一个接口；「证据」列必须是本仓库里可复核的文件路径 + 行号或 capture 目录。
> 未验证的推断写在「状态」列标 `推断`，不要混进「已复刻」。
